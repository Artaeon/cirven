install

$ cargo install --locked --git https://github.com/Artaeon/cirven cirven
$ cirven audit

linux only. rust 1.85+. experimental: read the threat model of a module before you rely on it.

principles

  • local first. works offline. no account required.
  • no telemetry. ever.
  • every change is shown before it happens and can be undone.
  • every module ships a threat model: what it stops, and what it does not.
  • least privilege: root only where the kernel demands it.
  • signed releases, reproducible builds.
