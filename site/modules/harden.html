cirven harden

Turns audit findings into fixes. Nothing changes without a plan you have read, and every applied plan can be rolled back.

usage

$ cirven harden --plan
1  sshd: PasswordAuthentication no            /etc/ssh/sshd_config.d/50-cirven.conf
2  nftables: default deny inbound, allow lo   /etc/nftables.conf
3  history: purge 1 secret, set HISTIGNORE    ~/.bash_history ~/.bashrc
$ cirven harden --apply 1,2
snapshot 2026-10-17T14:30Z saved. applied 2 changes.
$ cirven harden --rollback 2026-10-17T14:30Z

how

  • every fix is a small, declared change: a drop-in file, a sysctl, a mode bit
  • drop-ins over edits, so upstream configs stay untouched
  • files are snapshotted before change; rollback restores them byte for byte
  • fixes that could lock you out (ssh, firewall) apply with a dead-man timer: no confirmation within 60s, auto-rollback
  • profiles: laptop, dev, paranoid

threat model

Stops: the attack paths audit reports. Does not stop: what you re-enable later; run audit again. A leaked secret is purged locally, but it must still be rotated at its issuer.
