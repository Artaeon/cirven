cirven pkg

An AUR build script or an npm postinstall runs with your rights before you ever use the package. Malicious AUR packages shipping remote-access trojans have been found in the wild. pkg reads what will run before it runs.

usage

$ cirven pkg check aur/some-browser-bin
[high] source pulls from a personal github repo, not upstream
[high] install hook runs: curl -s https://... | python
[med ] maintainer account 3 days old, adopted orphan package
diff vs last version: +1 source, +1 install hook
verdict: do not install
$ cirven pkg wrap paru   # check every install automatically

signals

  • sources: domain changes, non-upstream hosts, missing or skipped checksums
  • scripts: network fetches, pipes to shells, base64 and eval, writes outside the package
  • history: diff against the previous version; new maintainer; recent adoption
  • npm/pip: install-time scripts, typosquat distance to popular names, binary blobs

threat model

Stops: the common, lazy supply-chain attacks, which are most of them. Does not stop: a patient attacker hiding logic in compiled upstream code. Pair with cage to build untrusted packages without network or home access.
