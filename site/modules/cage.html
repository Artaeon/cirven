cirven cage

Every program you run can read your whole home directory: your ssh keys, your browser profile, your cloud credentials. AI coding agents make this worse. They run commands, and a prompt injection hidden in a README is enough to steer them. cage gives a process the project it works on and nothing else.

usage

$ cirven cage --profile agent -- claude
fs:   rw ./  ro /usr  hidden: ~/.ssh ~/.aws ~/.gnupg ~/.config/chromium
net:  allow api.anthropic.com github.com registry.npmjs.org
$ cirven cage --net none -- makepkg

how

  • landlock for filesystem rules, no root required
  • user and mount namespaces (bubblewrap-style) to hide paths entirely
  • seccomp to drop syscalls a profile never needs
  • egress allowlist per profile; every denied connection is logged
  • profiles as plain text files you can read and diff

threat model

Stops: a confused or hijacked tool reading or sending what it should not. Does not stop: kernel exploits that escape the sandbox, or data you explicitly put inside the cage.
